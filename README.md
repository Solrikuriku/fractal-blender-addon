Аддон для Blender, который генерирует фракталы на основе заданных правил через концепцию L-систем.</br>
Разработан в 2022-м году в рамках курсовой работы.</br>
Изначально разрабатывался для версии 2.9.0. На данный момент подкорректирован и может открываться в версиях Blender от 4.х.</br>
В остальном код больше не дорабатывался.

Также можно настраивать количество итераций, угол, размер.

Первые четыре фрактала имеют базовые правила - F и G (дерево Пифагора). 
Однако у пользователя есть возможность экспериментировать с правилами и в базовых фракталах, не только в произвольных.
